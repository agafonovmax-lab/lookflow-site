Инструмент для автоматизации контент-фабрики

О проекте

LOOKFLOW Content Manager — это десктопное приложение (на базе Python и PySide6), разработанное для оптимизации и автоматизации рабочего процесса создателей контента и владельцев бизнес-аккаунтов.

Наше приложение помогает собирать данные о товарах, подготавливать визуальный контент (включая наложение текста и создание коллажей) и публиковать готовые материалы на различных платформах.

Как это работает

  • Сбор контента: Приложение агрегирует информацию и фотографии для будущих публикаций.
  • Обработка: Встроенные инструменты позволяют подготовить изображения к публикации в высоком качестве.
  • Публикация: Используя официальные API платформ, приложение публикует готовые посты и пины на доски пользователя.

Использование Pinterest API

Наше приложение запрашивает доступ к Pinterest API для выполнения следующих задач:

  • Чтение досок (boards:read): Чтобы показать список доступных досок пользователя для выбора места публикации.
  • Создание пинов (pins:write, pins:read): Для загрузки подготовленных изображений и публикации их в виде пинов на выбранные доски.

Приложение не собирает и не передает третьим лицам ваши личные данные. Весь контент публикуется исключительно от имени авторизованного пользователя.

Политика конфиденциальности

Мы уважаем вашу конфиденциальность и стремимся защищать ваши личные данные.

  • Сбор данных: Приложение не собирает персональные данные (такие как имя, адрес электронной почты или пароли). Авторизация происходит через официальный протокол OAuth 2.0 платформы Pinterest.
  • Использование данных: Токены доступа используются исключительно для выполнения запросов к API от вашего имени (например, для публикации пина). Мы не храним эти токены на сторонних серверах.
  • Передача данных: Мы не передаем, не продаем и не делимся вашими данными или токенами доступа с третьими лицами.
  • Безопасность: Приложение работает локально на вашем компьютере, что минимизирует риски утечки данных.
